# Infinity Craft

Браузерная песочница крафтов в духе Infinite Craft: соединяйте элементы, открывайте новые и собирайте собственную коллекцию. Никаких сборок и зависимостей — чистые HTML, CSS и JavaScript.

**Играть онлайн:** https://USERNAME.github.io/REPO/ — замените `USERNAME` на свой логин GitHub, а `REPO` на имя репозитория (см. «Публикация на GitHub Pages» в конце файла).

## Запуск

Две версии игры:

| Файл | Что это |
| --- | --- |
| `index.html` | обычная версия: начинаете с четырёх стихий и открываете элементы по шагам |
| `all.html` | отдельный файл «все элементы»: все 223 элемента и 483 рецепта открыты сразу; в основной игре ссылки на него нет |

В `all.html` есть ссылка на обычную версию; в основной игре ссылки на all-версию нет. Сохранения у версий отдельные, поэтому прогресс обычной игры не пострадает.

Проще всего открыть файл двойным кликом — игра работает прямо с диска.

Если браузер ограничивает сохранения на `file://`, запустите локальный сервер из папки проекта:

```bash
python -m http.server 8000
```

и откройте `http://localhost:8000`.

### Публикация на GitHub Pages

Сайт уже готов к публикации: `index.html` лежит в корне, есть `.nojekyll` (чтобы GitHub не обрабатывал файлы через Jekyll) и `.gitignore` (в репозиторий не попадают `tools/` и `shots/`).

1. Создайте репозиторий на GitHub — для бесплатного аккаунта он должен быть **публичным**.
2. Загрузите файлы (кнопка **Add file → Upload files** в веб-интерфейсе) или залейте через git:

```bash
git init
git add .
git commit -m "Infinity Craft"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```

3. Откройте **Settings → Pages**, в «Build and deployment» выберите **Deploy from a branch**, ветку **main** и папку **/(root)**, нажмите **Save**.
4. Через 1–10 минут сайт будет доступен по адресу `https://USERNAME.github.io/REPO/`. Версия со всеми элементами — `https://USERNAME.github.io/REPO/all.html`.

Важно: на бесплатном плане GitHub Pages работает только в публичных репозиториях ([документация](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)). Поэтому не выкладывайте папку `tools/` и экспорт «Мои рецепты» — в них могут быть личные данные.

### Переименование элементов (только all.html)

Переименование — админская функция all-версии; в основной игре её нет. Название любого элемента можно изменить — включая придуманные вами и те, что пришли из `recipes-user.js`. Имя сохраняется дословно: регистр, знаки и эмодзи не меняются.

- **✏️ на фишке** стола или **✏️ в панели** справа (появляется при наведении);
- кнопка **«✏️ Названия»** в шапке или «⋯» → «✏️ Изменить названия»: список элементов с поиском;
- в окне можно поменять не только название, но и эмодзи, и вернуть прежнее через «↺ Вернуть прежнее».

![Изменить названия](shots/all-editor.png)

Новое имя сразу видно на столе, в панели, в поиске и в книге рецептов, а после перезагрузки сохраняется.

Если элемент был создан старой версией, где к id добавлялся служебный хвост, при загрузке убирается только этот хвост; регистр, знаки и эмодзи сохраняются. Если старое сохранение уже успело потерять исходное написание, автоматически восстановить его невозможно — введите название один раз через ✏️, и оно больше не изменится.

![Окно переименования](shots/all-rename.png)

### Как перенести свои рецепты в основную игру

1. В all.html откройте «⋯» → «📝 Мои рецепты» → «📥 Скачать JSON». Файл `infinity-craft-proposals.json` попадёт в «Загрузки».
2. Запустите импорт:

```bash
node tools/import-proposals.mjs "C:\Users\igorp\Downloads\infinity-craft-proposals.json"
# или без пути — возьмёт последний такой файл из «Загрузок»:
node tools/import-proposals.mjs
```

3. Скрипт запишет рецепты в `recipes-user.js` и покажет список. Пары, которые уже есть в базе, пропускаются.
4. Перезагрузите `index.html` и `all.html` — ваши рецепты теперь в обеих версиях.

Придуманные вручную элементы получают внутренний id вида `custom:ледяной-алмаз-abc123`, а **название сохраняется ровно так, как вы его написали** — капс, многоточия, восклицательные знаки и эмодзи остаются как есть. При импорте id сохраняется, чтобы all.html не создавал дубликат, а имя по-прежнему пишется дословно, например:

```js
elements: { "custom:ледяной-алмаз-abc123": { name: "ЛЕДЯНОЙ АЛМАЗ!!! 🔥", emoji: "❄️", hue: 200 } },
recipes:  [["diamond", "penguin", "custom:ледяной-алмаз-abc123"]],
```

Если ввести название уже существующего элемента (даже капсом — «СНЕГ»), будет использован существующий элемент со своим именем, и новый дубликат не создаётся.

### Как сделать Жизнь

Путь 1 (6 шагов): `Вода + Огонь = Пар` → `Вода + Пар = Облако` → `Облако + Огонь = Молния` → `Ветер + Земля = Пыль` → `Вода + Пыль = Грязь` → **`Молния + Грязь = Жизнь`**.

Путь 2 (через Венеру): `Земля + Пыль = Планета`, `Вода + Дым = Туман` → `Планета + Туман = Венера` → **`Венера + Пар = Жизнь`**.

Из Жизни дальше получаются Рыба (`Жизнь + Вода`), Зверь (`Жизнь + Земля`), Птица (`Жизнь + Ветер`), Дракон (`Жизнь + Огонь`), Человек (`Жизнь + Пыль` или `Жизнь + Грязь`).

## Как добавить свои крафты

Все элементы и рецепты лежат в `recipes.js`. Добавьте элемент в объект `ELEMENTS`:

```js
ELEMENTS.coffee = { name: 'Кофе', emoji: '☕', hue: 28 };
```

и рецепт в массив `RECIPES` (тройка `[первый, второй, результат]`):

```js
['water', 'fire', 'coffee'],
```

Всё сразу подхватится при следующем открытии игры. Старые сохранения останутся рабочими: новые элементы просто появятся в коллекции после крафта.

Правила простые:

- `id` элемента — уникальная строка латиницей;
- имена не должны повторяться;
- порядок ингредиентов не важен: `вода + огонь` и `огонь + вода` — одна пара;
- одну и ту же пару нельзя объявить дважды (движок предупредит в консоли);
- у одного результата может быть несколько рецептов.

Проверить базу перед запуском:

```bash
node tools/check-recipes.mjs
```

Скрипт найдёт неизвестные id, дубли пар, повторяющиеся имена и недостижимые от базовых элементов крафты.

Посмотреть, как получить элемент, и самый короткий план:

```bash
node tools/recipe-paths.mjs life
node tools/recipe-paths.mjs человек время
```

## Сохранения

Прогресс хранится в браузере под ключом `infinity-craft.save.v1`: открытые элементы, рецепты, позиции фишек на столе и настройка звука. Сброс — через меню «⋯» → «Сбросить прогресс». Версия «все элементы» хранит стол отдельно под ключом `infinity-craft.all.save.v1`.

Если нужно перенести прогресс в другой браузер или сохранить резервную копию, используйте «Экспорт сохранения» и «Импорт сохранения» в том же меню.

## Проверка

В проекте есть браузерные тесты: основной проверяет крафт, настоящий drag&drop, перетаскивание из панели на стол (и отмену), возврат фишки в панель, новые крафты (Время, Бункер, У.Т.К.Э.Р, Lololowka, Смотрящий, Пещера, Конь, Искусство и т.д.), альтернативные рецепты, соединение кликом, книгу рецептов, поиск, сохранение после перезагрузки, мобильную вёрстку и очистку стола. Второй тест проверяет версию «все элементы».

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/run-browser-test.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tools/run-browser-test.ps1 -All
```

Последние прогоны: обычная версия — **67 из 67 проверок**, версия «все элементы» — **45 из 45 проверок** (выбор результата, появление придуманного элемента в панели, дословный текст, восстановление старых имён с регистром и знаками, переименование только в all-версии, сохранение имён после перезагрузки, отсутствие ссылки на all-версию и админских функций в основной игре, сброс до 4 стихий, «Мои рецепты» и drag&drop), ошибок страницы нет.
